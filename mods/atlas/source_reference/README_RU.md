# MAQAN v4

Что изменилось по вашим замечаниям:
1. **Файлы космических измерений < 60 КБ.** Каждый пак режется на несколько космических измерений (`..._space_1`, `_2`…); самый большой файл — см. `PACK_OVERVIEW_RU.md`.
2. **Файлов `dimension` для планет нет** — только для космоса. Планеты создаёте вы скриптом (Infiniverse + KubeJS). Это убирает ~884 измерений при создании мира; остаётся ~56 космических на ВСЕ паки.
3. **Больше канонических и лорных планет**: Star Wars 307 тел, Warhammer 337, Star Trek 171, Dune 69. Список новых — `CANON_ADDITIONS_RU.md`.
4. **Пересобрана раскладка по пакам**: слишком большие делятся (Outer Rim на три, Warhammer FRONT растворён по сегментумам), слишком маленькие объединены/пополнены (Dune 3 пака, Star Trek 6).
5. **PLANET_FORGE** — настройка рельефа и биомов каждой планеты под ваши моды (Terralith, BOP, Regions Unexplored, TerraBlender, Tectonic, Continents…). Читайте `PLANET_FORGE/README_RU.md`.

## Честные оговорки
- Ничего не запускалось в игре. Паки проверены валидатором (JSON, id=путь, звезда, travel_to, диапазоны, пересечения, GUI, ID-конфликты между всеми 29 паками): 0 ошибок.
- Dune: подтверждённых канонических планет в первичных источниках мало, добавлено только то, что нашлось (многое помечено `uncertain`/`derived`). Star Trek: часть звёзд и слотов — `derived`/заглушки «<Имя> Sun».
- Warhammer: раскладка 159 бывших FRONT-систем по сегментумам — по догадке (`REVIEW_GUESSES_RU.md`). Star Wars: деление Outer Rim на три по памяти.
- Новые планеты берут текстуры существующих планет того же типа.
- Паки START (SW_00, WH_00) оставлены как «иконические» наборы; при планетах-по-скрипту они больше не нужны для скорости.
- `ALTERNATIVE_LazyDims_mod` — прежний черновик Forge-мода (не собирался); теперь не нужен, если вы создаёте планеты скриптом.
