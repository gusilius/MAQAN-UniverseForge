# MAQAN Atlas

**Minecraft Forge 1.20.1 · Forge 47.4.28 · Java 17**

Atlas — самостоятельный космический мод экосистемы MAQAN UniverseForge. Исторический mod id `maqan_galactic_navigator` и Java package сохранены ради совместимости существующих установок, конфигураций и миров.

## Источники данных и границы ответственности

- Cosmic Horizons и активные датапаки — источник истины для звёздных систем, физических небесных тел, их исходных параметров и измерений.
- Atlas — источник истины для навигационного представления, каталогизации, пользовательских настроек, исследовательских данных и маршрутов.
- Atlas не подменяет данные Cosmic Horizons демонстрационной галактикой и не создаёт фиктивные планеты при отсутствии источника.
- Политика, население, государства, поселения, армии и династии принадлежат WorldForge. Atlas может отображать их через необязательный bridge, но не симулирует их.

## Уже присутствующие подсистемы

- Каталог Cosmic Horizons, адаптер datapack JSON и сканер синхронизированных данных.
- Модели вселенной, галактик, секторов, систем и небесных тел.
- 2D / гибридная / перспективная 3D-навигация.
- Кубические GUI-модели и исходные текстуры Cosmic Horizons.
- Орбитальная симуляция, параметры движения и контроллер орбит Cosmic Horizons.
- Отдельные визуальные рендереры космической среды и звёздных объектов.
- Планирование маршрутов, перехват движущихся целей, препятствия и серверная проверка назначения.
- Поверхностная карта, 3D-рельефный просмотрщик, путевые точки и маркеры игрока.
- Сохраняемые рабочие пространства и настройки интерфейса.
- Java fallback для вычисления layout; Rust core остаётся дополнительным нативным компонентом.

## Правила стабилизации Atlas

1. Единый авторитетный источник времени и состояния движения для навигатора и игровых рендереров.
2. Никакого независимого «красивого» движения в UI, расходящегося с физическими координатами в мире.
3. Все преобразования локальных орбитальных координат и глобального размещения систем должны оставаться раздельными.
4. Неоднозначные многозвёздные системы не получают выдуманного центрального тела.
5. Неизученные области поверхности не маркируются как исследованные.
6. Отсутствие Cosmic Horizons, задержка sync и повреждённые записи должны давать понятное состояние источника, а не фиктивные данные.
7. Нативная библиотека не обязательна для запуска: Java fallback сохраняет работоспособность при отсутствии платформенной Rust-библиотеки.
8. Переопределения пользователя хранятся отдельно от исходных datapack-данных.

## Управление

- `M` — открыть Atlas.
- ЛКМ по объекту — выбрать.
- ЛКМ + drag — вращение карты.
- ПКМ + drag — перемещение карты.
- Колесо — масштабирование.
- ПКМ по небесному телу — контекстные действия и редактор орбиты.

## Сборка

Из `mods/atlas`:

```bash
gradle --no-daemon build
```

Артефакт: `build/libs/maqan-atlas-*.jar`.

Проверка Gradle не заменяет запуск Minecraft Forge 47.4.28 с Cosmic Horizons 0.0.7.3 и реальными датапаками.
