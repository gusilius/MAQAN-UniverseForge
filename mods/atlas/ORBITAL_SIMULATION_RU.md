# Орбиты и движение тел MAQAN Galactic Navigator

## Что берётся из Cosmic Horizons

Стандартные данные Cosmic Horizons дают начальные координаты тел (`xpos`, `ypos`, `zpos`) и визуальные параметры мини-планет. Стандартная схема не задаёт универсальные орбитальные периоды и связи «спутник → родительское тело».

MAQAN использует координаты datapack'а как исходную геометрию. Для обычной системы с одной звездой планеты, астероиды и кометы автоматически получают круговую визуальную орбиту вокруг этой звезды. В системах с несколькими звёздами автоматическое назначение звезды отключено: там требуется явная родительская связь.

Без параметров периода MAQAN включает **ускоренный визуальный режим**, а не заявляет физически точные скорости: внутренние орбиты движутся быстрее внешних. Период рассчитывается по радиусу: примерно 1800 тиков при радиусе 10000 единиц, с ограничением диапазона 1200–6000 тиков. Отсчёт начинается в момент создания состояния орбит, поэтому первая позиция совпадает с координатами datapack и не зависит от времени, прошедшего в мире до открытия навигатора.

Параметры собственного вращения Cosmic Horizons (`yaw`, `pitch`, `roll` и `*_speed`) передаются в радианах напрямую в `Axis.rotation()`, без перевода в градусы. Если `yaw_speed` отсутствует или равен нулю, GUI задаёт запасное вращение по оси Y (0.012 радиана на игровой тик). Ненулевые скорости из datapack сохраняются.

## Явные параметры орбиты

Их можно добавить в объект GUI-планеты (в `gui_data.<category>.object_data.<body>`) или в физический объект `planet_data.<body>`. GUI-адаптер MAQAN сохраняет эти поля при объединении данных.

Рекомендуемый формат:

```json
{
  "maqan_orbit": {
    "parent_id": "sun",
    "semi_major_axis": 12000,
    "period_ticks": 24000,
    "eccentricity": 0.0167,
    "inclination_degrees": 7.0,
    "ascending_node_degrees": 12.0,
    "argument_of_periapsis_degrees": 25.0,
    "phase_degrees": 0.0
  }
}
```

Поля:

| Поле | Значение |
|---|---|
| `parent_id` | ID/ключ родительского тела в системе. Также поддерживаются `parent`, `parent_dimension_id`, `satellite_of`. |
| `semi_major_axis` | Большая полуось; единицы совпадают с координатами Cosmic Horizons. |
| `orbit_radius`, `orbital_distance` | Альтернативные имена большой полуоси. |
| `period_ticks` | Период в игровых тиках. 20 тиков = 1 секунда реального времени. |
| `period_seconds` | Период в секундах; MAQAN переводит его в 20 игровых тиков на секунду. |
| `orbital_period`, `orbital_period_days` | Период в игровых днях; 1 игровой день = 24000 тиков. |
| `eccentricity` | Эксцентриситет от 0 до 0.95. 0 означает круговую орбиту. |
| `inclination_degrees` | Наклон плоскости орбиты в градусах. Если не задан, плоскость подбирается по исходному 3D-положению тела. |
| `ascending_node_degrees` | Долгота восходящего узла в градусах. |
| `argument_of_periapsis_degrees` | Аргумент перицентра в градусах. |
| `phase_degrees` | Начальная средняя аномалия в градусах, отсчитываемая от момента открытия орбитальной симуляции. |

Если большая полуось не задана, MAQAN выводит её из текущего расстояния между телом и родителем. Если период не задан, используется визуальный период MAQAN. При заданном эксцентриситете стартовая позиция сохраняется по исходным координатам, когда фаза не переопределена.

## Ссылки на родительские тела

Поддерживаются верхнеуровневые поля `parent`, `parent_id`, `parent_body`, `parent_dimension_id`, `satellite_of`, `central_body`, `orbit_parent`, `orbit_parent_id`, а также те же поля внутри `maqan_orbit`, `orbit_data` или `orbit`.

Планеты без явной связи автоматически привязываются к звезде только при наличии ровно одной звезды. Звезда определяется по типу и распространённым именам `Sun` / `Sol`; если у единственной звезды нет координат, для неё используется системный ноль (0, 0, 0). Для систем с несколькими звёздами автоматический центр не выбирается. Луны/спутники автоматически привязываются к планете только в однопланетной системе; в остальных случаях задайте `parent_id`.

## Отображение

- 2D-карта показывает контрастные орбитальные контуры в плоскости XZ.
- Перспективная 3D-карта показывает контуры и движущиеся маркеры.
- Кубическая модель вращается автоматически даже при нулевом `yaw_speed`; её также можно вращать мышью.
- При открытии планеты её дочерние спутники отображаются вокруг выбранного тела.
- Масштаб карты учитывает размер орбит, а не только начальные позиции тел.
- Собственное вращение кубической модели планеты остаётся отдельной системой и продолжает управляться мышью.

## Ограничения

Визуальный период по умолчанию нужен для наглядности и не является реальной астрономической величиной. Для бинарных и кратных систем указывайте родительские связи явно. N-body режим с `speed`, `mass` и `astronomical_compute` — отдельный путь для наборов данных с согласованными физическими единицами; обычные datapack-координаты Cosmic Horizons сами по себе не содержат полной физической начальной скорости.
