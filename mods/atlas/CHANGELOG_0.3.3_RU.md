# MAQAN Galactic Navigator 0.3.3

## Иерархическая навигация

- Первый уровень навигации обозначен как сектор/исходный datapack (`pack`).
- Второй уровень — звёздная система (`system`).
- Добавлен режим `SCOPE: SYSTEM`: после выбора объекта можно сфокусировать список на его звёздной системе.
- Детали выбранного объекта показывают галактику, сектор/pack и систему отдельно.
- В `GalaxyCatalog` добавлены методы получения списка секторов, систем внутри сектора и тел внутри системы.
- Исходные JSON-данные и координаты не переписываются.

## Ограничения

`pack` пока используется как группировочный сектор, поскольку в исходном каталоге нет отдельных геометрических границ секторов. Это не означает, что мод уже вычисляет реальные объёмные границы регионов. Следующий шаг — добавить в JSON необязательные метаданные сектора (id, display name, parent region, bounds/shape) и визуализировать их.

Java/Gradle build и запуск в Forge не подтверждены в этой среде.
