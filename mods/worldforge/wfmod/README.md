# WorldForge (мод): мир из картинки

Мод для **Minecraft 1.20.1, Forge 47.x**. Он читает пакет карты, созданный инструментом `worldforge`
(или нарисованный тобой вручную), и строит по нему измерение: рельеф из карты высот, биомы из карты биомов,
реки из маски рек. Подходит и как основной мир, и как дополнительное измерение (например для Cosmic Horizon).

> **Важно: статус.** Чистая логика (чтение пакета, высоты, реки, биомы, спавн, шум, пещеры) проверена
> на настоящем пакете Planetos. А вот классы, которые вызывают API Minecraft/Forge
> (`MapChunkGenerator`, `MapBiomeSource`, `WorldForgeMod`), я **не смог собрать и запустить**: в моей среде нет доступа
> к репозиториям Forge. Они написаны по API 1.20.1 и могут потребовать мелких правок при первой сборке.
> Присылай ошибки компиляции или лог, исправим.

## Как это связано с Cosmic Horizons
Cosmic Horizons делает каждую планету **обычным датапак-измерением** и описывает её файлом в
`data/<ns>/cosmos/cosmic_data/` (гравитация, высота атмосферы, куда лететь). Мод WorldForge даёт этому измерению
генератор «по картинке», поэтому для планеты достаточно датапака, который собирает инструмент `worldforge planet`
(см. его README). В датапаке лежит и сама карта: `data/<ns>/worldforge_maps/<имя>/`, поэтому ничего не нужно копировать
в `config`. В `generator.map` пишется `"ns:имя"` для карты из датапака или просто `"имя"` для карты из `config/worldforge/maps/`.
Новая планета не требует пересборки мода: добавь картинку, выполни команду, положи датапак.

## Сборка без установки: через GitHub (рекомендую)
В проекте уже лежит `.github/workflows/build.yml`, поэтому ничего ставить не нужно:
1. Создай на github.com пустой репозиторий и загрузи в него содержимое этой папки (кнопка Add file → Upload files, либо `git push`).
2. Открой вкладку **Actions**. Сборка стартует сама (или нажми Run workflow).
3. Через 3-5 минут внизу страницы запуска появится файл **worldforge-mod**: внутри готовый `worldforge-0.1.0.jar`.
4. Если сборка красная, открой шаг «Сборка мода» и пришли мне строки с `error:`: я исправлю код.

## Сборка на своём компьютере
1. Нужен JDK 17. Gradle 8.1.1+ (проще всего скопировать `gradlew`, `gradlew.bat` и `gradle/wrapper/gradle-wrapper.jar`
   из официального Forge MDK 1.20.1 или выполнить `gradle wrapper`).
2. `./gradlew build` → готовый мод в `build/libs/worldforge-0.1.0.jar`.
3. Для запуска из среды разработки: `./gradlew runClient`.

## Установка и запуск
1. Положи `worldforge-*.jar` в `mods/` (на сервер и на клиент).
2. Положи пакет карты: `config/worldforge/maps/planetos.worldmap` (пример лежит в `examples/maps/`).
   Вместо `.worldmap` можно положить папку `config/worldforge/maps/<имя>/` с файлами пакета
   или прямо папку проекта инструмента (мод сам найдёт в ней `out/`).
3. Создание мира: в «Тип мира» выбери **WorldForge: Планетос**. В этом режиме есть только Верхний мир.
4. Как дополнительное измерение: используется датапак-измерение `worldforge:planetos`
   (`/execute in worldforge:planetos run tp @s 0 120 0`).
   Твои измерения: скопируй `data/worldforge/dimension/planetos.json` под своим именем и поменяй `"map"`.

## Регионы и политическая карта
Если в пакете карты есть `regions.png` и `regions.json` (их создаёт `worldforge regions`), мод:
* знает регион игрока в любой точке (`MapData.regionAt(x, z)`);
* раз в секунду проверяет регион игрока и при смене показывает над панелью предметов «Вы вошли в: <регион>»;
* публикует **`RegionEnterEvent`** на `MinecraftForge.EVENT_BUS`. Это точка для будущих действий (налоги, войны, квесты, бонусы
  региона). У региона есть `props` из твоего `regions.json`. Пример:
```java
@SubscribeEvent
public void onEnter(RegionEnterEvent e) {
    if (e.getTo() != null && "Дорн".equals(e.getTo().name)) { /* что-то сделать с e.getPlayer() */ }
}
```
* команды (права оператора): `/worldforge regions` (список), `/worldforge region` (где я), `/worldforge region tp <название>`
  (в столицу, достаточно части названия), `/worldforge politicalmap` (карта-предмет).

Карта-предмет это обычная карта Minecraft 128x128 с палитрой ванильных цветов: работает и без мода на клиенте, её можно повесить в рамку
в тронном зале. Минус: разрешение низкое (мелкие регионы почти не видны). Следующий шаг: экран с большой картой, зумом и подсказкой
с названием региона под курсором (ему понадобится свой пакет данных клиенту).

## Иерархия и государства (в стиле Paradox)
Если в пакете есть `provinces.png`, `titles.json` (и `realms.json`), мод знает всю цепочку титулов и государство в любой точке:
`MapData.provinceAt(x, z)` → `TitleData.chain(...)`, `ancestor(...)`, `realmOf(...)`, `overlordChain(...)`.
Команды (операторы):
* `/worldforge title`: цепочка титулов в вашей точке (империя → … → баронство), государство и цепочка сюзеренов с типом отношения;
* `/worldforge realms`: дерево государств, независимые сверху, подчинённые с отношением (вассал, данник...);
* `/worldforge realm <имя>`: правитель, сюзерен, титулы, подчинённые;
* `/worldforge politicalmap [barony|county|duchy|kingdom|empire|realms]`: карта-предмет нужного уровня (по умолчанию государства).

Событие **`TitleEnterEvent`** срабатывает при смене провинции. Из него можно подняться по иерархии и узнать государство:
```java
@SubscribeEvent
public void onProvince(TitleEnterEvent e) {
    TitleData.Realm realm = e.getRealm();            // чей это владения (или null)
    TitleData.Title kingdom = e.tier(3);             // королевство, к которому относится провинция
    // тут будут налоги, враждебность, баффы и т.д.
}
```

## Карта в игре, миникарта, веб-карта, метки

Нужен мод и на сервере, и на клиенте. При входе (и после каждой правки редактора) сервер присылает клиенту титулы и государства; рельеф кэшируется в `config/worldforge/cache/`.

**Клавиши (меняются в настройках управления):** `M` открыть карту, `N` включить и выключить миникарту.

**Экран карты.** Режимы как в Paradox: рельеф, баронства (провинции), графства, герцогства, королевства, империи, государства (вассалы и данники заштрихованы цветом сюзерена). Кнопки сверху или цифры `1`-`7`. Колесо мыши меняет масштаб, перетаскивание сдвигает. Наведение показывает цепочку титулов и государство и подсвечивает титул выбранного уровня. Клик выбирает провинцию и открывает панель: правитель, сюзерены, подчинённые, площадь, соседи. Названия появляются по мере приближения и не перекрывают друг друга. `C` центрирует на вас, Shift+ПКМ телепортирует оператора в точку на карте.

**Вейпойнты** (личные, хранятся на вашем компьютере, свои для каждой карты): `B` над точкой карты, ввести название, Enter. `Delete` над меткой удаляет её. Файл: `config/worldforge/waypoints_<карта>.json`.

**Миникарта** в углу показывает окрестности в текущем режиме и название провинции. При входе в другое королевство появляется баннер с его названием и государством.

**Метки сервера** (города, замки, порты, руины, лагеря, храмы, шахты), видны всем на карте в игре и в вебе:
```
/worldforge marker add <тип> <название>    в точке, где вы стоите
/worldforge marker remove <id>
/worldforge marker list
/worldforge marker tp <id>
/worldforge tpxz <x> <z>                   телепорт на поверхность
```
Метки лежат в `<мир>/worldforge/<карта>/markers.json`.

**Веб-карта** (как Dynmap): сервер сам поднимает страницу на порту 8123 (`/worldforge web` покажет адрес). Те же режимы, поиск по титулам, государствам и меткам, панель титула, игроки на карте. После правок редактора страница обновляется сама. Настройки в `config/worldforge/web.json`: `enabled`, `port`, `bind` (`0.0.0.0` для доступа извне, `127.0.0.1` только с сервера), `show_players`, `map` (если на сервере несколько карт, какую показывать). Страница только читает данные, управлять с неё нельзя; откройте порт в файрволе, если нужен доступ из интернета.

## Режим редактора (для админа в творческом режиме)

Работает для операторов (уровень 2) в творческом режиме, на картах с титулами (есть `provinces.png` и `titles.json`).

```
/worldforge editor on            включить режим
/worldforge editor wand          выдать жезл картографа (блейз-род с меткой)
```

**Жезл.** ПКМ закрашивает провинцией выбранной, дальность до 160 блоков, радиус кисти задаётся командой. Shift+ПКМ или ЛКМ по блоку выбирают провинцию под прицелом. ЛКМ не ломает блоки. Земля меняется только там, где уже есть суша: берег и море кисть не трогает. Пока жезл в руке, частицами видны границы: белые (END_ROD) показывают границы выбранного уровня, пламя показывает выбранную провинцию, синее кольцо показывает кисть.

Основные команды (`<уровень>`: barony, county, duchy, kingdom, empire; цель это титул этого уровня у выбранной провинции):

| Команда | Что делает |
|---|---|
| `editor level <уровень>` | границы какого уровня подсвечивать |
| `editor brush <блоков>` | радиус кисти (разрешение карты ≈ blocks_per_pixel, у карты 10к/2048 это ≈4.9 блока; для тонких границ строй карту с resolution 4096) |
| `editor select [имя]` | выбрать провинцию под ногами или по имени |
| `editor info` | цепочка титулов, государство, площадь |
| `editor undo`, `editor redo` | отмена и повтор (40 шагов) |
| `editor tool brush\|smooth\|assign <уровень>` | инструмент жезла: закрасить, сгладить границы или назначить (ПКМ по провинции переносит её под выбранный титул этого уровня) |
| `editor validate` | проверка: разорванные и пустые провинции, неверная иерархия, странные государства |
| `editor rename/color/prop <уровень> …` | имя, цвет `#rrggbb`, свойство титула |
| `editor move <уровень> <титул-родитель>` | перенести титул в другой (например герцогство в другое королевство) |
| `editor new <уровень> <имя>` | новый титул внутри текущего; новая провинция пустая, её закрашивают жезлом |
| `editor delete <уровень>` | удалить титул; земля провинции переходит соседу с самой длинной границей, дети переходят к родителю |
| `editor capital <уровень>` | столица титула там, где вы стоите |
| `editor realm create/delete/rename/ruler/color <…>` | государства |
| `editor realm give/take <id> <уровень>` | передать или отобрать титул |
| `editor realm overlord <id> <сюзерен\|none> [тип]` | сюзерен и тип отношений (vassal, tributary, protectorate, puppet, personal_union); циклы запрещены |
| `editor realm relation <id> <тип>`, `relparam <тип> <параметр> <значение>` | тип отношений и его параметры (tribute, levy, can_declare_war) |
| `editor save`, `editor refresh`, `editor off` | сохранить, перерисовать карты-предметы, выключить |
| `editor export` | выгрузить `titles.json`, `realms.json`, `provinces.png` в `config/worldforge/export/<карта>/` |

**Где хранятся правки.** Автосохранение раз в минуту, при выходе с сервера и по `editor save`. Файлы лежат в `<мир>/worldforge/<карта>/` и накладываются поверх пакета карты при каждой загрузке, поэтому исходный пакет не меняется. Карты-предметы (`/worldforge politicalmap`) перерисовываются по правкам автоматически; узоры подчинённых на них упрощены.

**Вернуть правки в проект.** Скопируйте папку из `config/worldforge/export/<карта>/` и выполните в инструменте `python -m worldforge import-edits projects/<проект> <папка>`: пересчитаются площади, соседи, столицы, перерисуются красивые карты `political_*.png` и карты-предметы, а прежние файлы сохранятся в `out/_before_edits/`.

## Свой мир
```json
{
  "type": "worldforge:mapworld",
  "generator": { "type": "worldforge:image", "map": "моя_карта", "caves": true, "detail": 1.0 }
}
```
* `map`: имя пакета в `config/worldforge/maps/`.
* `caves`: пещеры (по умолчанию `true`).
* `detail`: сила мелкого рельефа поверх карты (0 даёт гладкий рельеф ровно по карте).

Карта центрирована в точке (0, 0): пиксель в середине картинки лежит в начале координат.
За краем карты тянется то, что нарисовано на краю (обычно океан).

## Формат пакета (если рисуешь сам, без инструмента)
| файл | содержание |
|---|---|
| `meta.json` | `size_px [w,h]`, `blocks_per_pixel`, `sea_level`, `min_y`, `max_y`, `biomes[]` (`index`, `key`, `candidates[]`), необязательно `spawn [x,y]` в долях картинки |
| `biomes.png` | 8 бит, индекс пикселя = индекс биома из `meta.json` |
| `height16.png` | 16 бит серый, `Y = min_y + значение/65535·(max_y−min_y)` |
| `rivers.png` | необязательно, 8 бит: 0 суша, 160 озеро, 255 река |
| `regions.png`, `regions.json`, `regionmap.bin` | необязательно: плоские регионы (индекс на пиксель, описание, карта-предмет) |
| `provinces.png`, `titles.json`, `realms.json`, `mapitem_*.bin` | необязательно: иерархия титулов, государства и отношения, карты-предметы по уровням |

`candidates` это список ID биомов по приоритету; мод берёт первый, который есть в игре. Так мир работает
и без Terralith/Biomes O' Plenty (тогда будут ванильные биомы). Все четыре файла должны быть одного размера.

## Команды (нужны права оператора)
* `/worldforge info`: карта текущего измерения, размер мира.
* `/worldforge reload`: сбросить кэш карт.

В отладочном экране F3 в строке WorldForge видно ключ биома карты и признак реки.

## Что умеет и чего нет
**Есть:** рельеф по карте высот с мелкой детализацией; реки и озёра с руслом и ровной водой; биомы по картинке с «дрожащими»
границами; поверхностные блоки по биому (песок, красный песок и терракота, снег, подзол, ил...); пещеры;
океанское дно; ванильные деревья, руды, структуры и мобы (через биомы Minecraft); безопасная точка спавна на суше.

**Пока нет:** генерации пещерных биомов (lush/dripstone), водопадов, карьеров-оврагов, аквиферов, подземных озёр лавы;
поддержки Nether/End в пресете. Поверхностные правила не подхватывают собственные блоки Terralith/BOP
(биомы подключаются, но верхний блок задаёт WorldForge). Всё это можно добавить следующими версиями.

## Оформление карты (в стиле CK3 с материалами Minecraft)

Окно в игре и веб-карта выглядят одинаково:

- **Хотбар режимов** внизу: слоты со значками, группы разделены (рельеф | уровни титулов | государства | свойства), номер слота = клавиша 1-9.
- **Режимы по свойствам**: любое свойство титулов (`/worldforge editor prop <титул> culture Андалы`) автоматически становится режимом карты (культуры, религии, дома...). Значение наследуется вверх по иерархии: свойство можно задать графству, и оно действует на все его баронства. Цвета значений назначаются автоматически и одинаковы в игре и в браузере.
- **Легенда** слева внизу для режимов свойств и государств (в вебе клик по строке переносит к региону).
- **Обзор** справа внизу: уменьшенная карта текущего режима с рамкой видимой области; клик и перетаскивание двигают вид.
- Рамки со скосом, как у слотов инвентаря; тень и рамка вокруг карты; шкала масштаба; координаты под курсором.

Предпросмотр окна без игры: `tools/uipreview/README.md` (заглушки Minecraft рисуют `MapScreen` в PNG).

## Боковые панели и слои

Окно карты в игре (клавиша M) и веб-карта показывают справа рейку вкладок (в игре Tab открывает и закрывает панель):

| Вкладка | Что внутри |
|---|---|
| Титул | цепочка титулов, площадь, столица, переход к ней |
| Государство | правитель, сюзерен и отношение, свойства, земли, подчинённые (клик переносит на карту) |
| Дипломатия | дерево подчинения, счётчики отношений, правила видов отношений, действия сервера (в игре кнопки, в вебе копирование команды) |
| Редактор | только оператору в творческом режиме: кисть, сглаживание, назначение титула, откат и повтор, проверка, сохранение; правка кликом и протяжкой прямо по карте |
| Метки | метки сервера и личные вейпойнты |

**Дипломатический слой** (кнопка в хотбаре или кнопка «Дипломатический слой» на вкладке): выбранное государство и остальные окрашиваются по отношению к нему: сюзерены, подчинённые, вассалы того же сюзерена, союзники, враги, соседи. Союзы и войны берутся из свойств государства `allies` и `enemies` (списки id через запятую): `/worldforge editor realm prop <id> enemies other_realm`.

## Для аддонов (NPC, дома, войны, дипломатия)

Основной мод ничего не знает о людях и армиях. Аддон подключается тремя способами, все без изменения этого мода:

1. **Данные.** Свойства титулов и государств (`props`) уходят клиентам и на веб-карту и сами становятся режимами карты (`p:<ключ>`). Название, порядок и цвета значений задаются в `realms.json` в разделе `prop_defs`:
   `"prop_defs": {"house": {"name": "Дома", "order": ["Старк", "Ланнистер"], "colors": {"Старк": "#8899aa"}}}`.
   Свойство государства действует на все его земли, свойство титула наследуется вниз по иерархии.
2. **Действия.** `WorldForgeApi.registerAction(new MapAction(id, подпись, REALM|TITLE|MAP, ANY|OP, параметры, подсказка, обработчик))`. Действие появляется кнопкой во вкладке «Дипломатия» у всех игроков и запускается командой `/wfaction run <id> <цель> [арг1 | арг2]`. Права проверяет само действие, а `WorldForgeApi.addGuard` позволяет аддону запретить чужое действие с сообщением (например «идёт война»). Встроенные примеры: `set_ruler`, `set_overlord`, `release`, `set_prop` (`api/BuiltinActions.java`).
3. **События.** `WorldForgeApi.addChangeListener` и событие Forge `MapChangedEvent` сообщают о любой правке и действии. Любая правка через `TitleEditor` сама поднимает версию карты: клиенты и веб-карта получают её без дополнительных вызовов.

Пример: аддон войн при объявлении войны вызывает `editor.setRealmProp(a, "enemies", b)` и `editor.setRealmProp(b, "enemies", a)`. Дипломатический слой, вкладка и веб-карта обновятся сами.
