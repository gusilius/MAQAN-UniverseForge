# WorldForge: аддоны

Каждый аддон - отдельный Gradle-проект и отдельный мод (`wf_*`). Все зависят **только от ядра `worldforge`** (чистое API: `dev.worldforge.mod.api`, `TitleData`, `TitleEditor`), друг на друга - только через мягкие мосты (`bridge`), которые подгружаются, если второй мод стоит. Сломав один аддон, остальные не ломаешь.

## Карта модулей

| Аддон | Что делает | Данные (датапак) | Мягко дружит с |
|---|---|---|---|
| `wf-dialogue` | Движок диалогов: узлы, варианты, условия, эффекты, `{переменные}` | `wf_dialogue` | - |
| `wf-reputation` | Репутация игрока с фракциями (-100..100), отклик вверх по цепочке, затухание | `wf_factions` | dialogue |
| `wf-people` | Роли (правитель, канцлер, маршал...), персонажи, дворы, дома, браки, наследование | `wf_roles`, `wf_names` | dialogue |
| `wf-settlements` | Поселение: склад, здания, рабочие и профессии, стройка, добыча, рост/голод, приказы как в RTS | `wf_settle` | people |
| `wf-war` | Войны, поводы, очки, мир, перемирия, союзы; итоги меняют карту | `wf_war` | people |

```
worldforge (ядро: карта, титулы, государства, API действий)
   ^   ^   ^   ^   ^
   |   |   |   |   +-- wf-war
   |   |   |   +------ wf-settlements
   |   |   +---------- wf-people ..... bridge -> wf-dialogue
   |   +-------------- wf-reputation . bridge -> wf-dialogue
   +------------------ wf-dialogue
```

## Правила
1. Аддон не читает чужие классы напрямую: только данные (`props` государств/титулов), события (`WorldForgeApi.addChangeListener`), действия (`registerAction`) и реестры.
2. Свойства называются с префиксом аддона: `war.state`, `war.truce_until`. Общие для дипломатии: `allies`, `enemies` - их понимает слой карты «Дипломатия».
3. Контент (роли, диалоги, здания, поводы) - JSON в датапаке: новое добавляется файлом, без Java.
4. Чистая логика отдельно от Minecraft (`mc/` - только склейка). Чистая часть тестируется без игры: `tools/test-all.sh`.
5. Права на действия проверяет `WarEngine.Authority`: по умолчанию оператор или правитель государства; мост к `wf-people` может разрешать маршалам и канцлерам (`unlocks` роли: `war`, `peace`, `alliance`).

## Состояние
- Готово и проверено тестами (чистая Java): диалоги, репутация, люди/роли/дворы/наследование, совет, фракции, козни, события, поселения (здания, казна, торговля, комфорт, приоритеты работ, RTS-модель, времена года, набеги), династические браки, торговые договоры, экономика государства (статьи дохода, налоги, развитие баронств, дань), снабжение армий, войны/дипломатия, армии, осады, битвы и ИИ.
- Написано, но не компилировалось (нет Forge toolchain; ничего не проверено): склейка `mc/` для wf-dialogue (сессии, пакеты `wf_dialogue:main`, `DialogueScreen`), wf-reputation (сохранение, `/wfrep`) и wf-people (сущность `WFNpc`, загрузка `wf_roles`/`wf_names`, сохранение `wf_people.json`, спавнер у столиц, `/wfpeople`). Нужен первый запуск GitHub Actions и лог.
- Не сделано (старое описание остаётся для wf-settlements/wf-war): склейка с Minecraft - сущность NPC, экран диалога и пакеты, появление тел рабочих рядом с игроком, постройка блоками по чертежам, загрузчики датапаков, сохранение в мир. Эти части нельзя проверить без сборки: нужен первый запуск GitHub Actions и лог.

## Окна и управление
Все окна рисуют общим набором `WFUi` (ядро) и получают состояние от сервера (`WFNet.sendView` -> `ClientViews`), а приказы отправляют обычными командами (`ClientViews.command`): окна не меняют мир сами.

| Клавиша | Команда | Окно |
|---|---|---|
| H | `/wfsettle view hud` | RTS-панель поселения (ресурсы, выделение, карточка команд 4x3, группы Ctrl+1..9, матрица работ P) |
| J | `/wfsettle view panel` | Окно поселения: Обзор, Здания, Люди, Строить, Торговля, Бюджет, Города (сводная таблица), Журнал |
| K | `/wfwar screen [государство]` | Войны, Армии, Дипломатия, Экономика, Реестр, Журнал |
| V | `/wfcourt [государство]` | Двор (`/wfcourt play <id>`, `play realm <государство>`, `release`: игрок ведёт героя, после смерти переходит к наследнику): Совет, Вассалы (фракции), Козни, События, Браки, Хроника |

Государство по умолчанию - то, на чьей земле стоит игрок. Окна обновляются сами раз в 1-2 секунды.

Новые данные (датапак): `wf_settle/*.json` (здания, цены, комфорт, профессии), `wf_war/units.json` (типы отрядов и их сильные стороны), `wf_people/wf_events/*.json` (события с вариантами и последствиями), роли получают блок `council` (характеристика и эффекты для государства).

Связи между аддонами идут только через свойства государств и действия карты: совет пишет `council.income_pct|levy_pct|commander|...` (армии берут `council.commander` как умение полководцев), фракции вассалов вызывают действие `war_independence`.

## Команды управления
Права: оператор, а также владелец одиночного мира (даже без читов) - `WFPerm.trusted` в ядре. На сервере остальные игроки действуют через роли (правитель, канцлер, маршал) и проверки действий; команды поселения без прав оператора на сервере недоступны.

`/wfsettle`: `priority-work <рабочий> <профессия> <0-4>`, `pause <здание> <true|false>`, `tax <0-3>`, `buy|sell <ресурс> <число>`, `trade-auto <ресурс> sell|buy|off <порог>`, `view <panel|hud> [город]`, `route add <из> <в> <ресурс> <ед/мин>`, `route remove <номер>` (торговые маршруты между городами: караван возит товар из дешёвого города в дорогой, цены сближаются). Цены на рынке поселения плавающие: дефицит дорожит, избыток дешевит, покупки и продажи двигают цену.
Действия карты (`/wfaction run`): `army_raise|army_hire|army_move|army_stop|army_merge|army_disband`, `scheme_start|scheme_cancel`, `faction_appease|faction_crush`, `event_choose`, `marriage_propose <наш персонаж>|<их персонаж>`, `trade_propose|trade_cancel <государство>`, `econ_develop <баронство>`, `econ_tax <0-2>`, `econ_tribute <0-30>`. Несколько аргументов разделяются знаком `|`.

## Мосты и права (склейка `mc/`)
- people -> dialogue: `PeopleMod.interact` публикует `NpcInteractEvent`, затем (если загружен `wf_dialogue`) через `DialogueHook` зовёт `DialogueMc.open` рефлексией; id диалога - `props.dialogue` персонажа, иначе `dialogue` роли, иначе `default` (если файла роли нет, открывается `default`). Условия `npc_role`, `npc_house`, `npc_trait` регистрирует `people.bridge.DialogueBridge`.
- reputation -> dialogue: `reputation.mc.DialogueLink` (только при `wf_dialogue`) регистрирует `rep_at_least`, `rep_at_most`, `standing_is`, `rep_add` и кладёт `ReputationStore` в контекст; `player_id` ставит `DialogueMc.open`.
- Права для wf-war: `wf-war` не зависит от `wf-people`, поэтому реализовать `WarEngine.Authority` внутри people нельзя. Вместо этого wf-war может звать рефлексией (если мод `wf_people` загружен)
  `dev.worldforge.people.mc.CapabilityCheck.mayAct(String actor, String realmId, String capability) -> boolean`
  (игрок держит в государстве роль с таким `unlocks`; связь игрок-персонаж: `props.player` персонажа = UUID или имя игрока)
  и `CapabilityCheck.realmHas(String realmId, String capability)` (есть ли вообще такой носитель). При любой ошибке возвращается `false`.

## Общение с жителями (wf-people + wf-dialogue)
Слой `Relations` (чистая логика, `RelationsTest`) хранит для пары «игрок - персонаж» симпатию (-100..100, сердца 0-5), любовь, перезарядки, свидание/брак, найм.
- **Общение** (в духе MCA): поболтать, пошутить, комплимент, флирт, обнять, поцеловать, оскорбить. Исход зависит от черт собеседника (общительный, робкий, жестокий...) и случая. Без общения симпатия остывает.
- **Подарки**: предмет из руки, ценность 1-10, после трёх подарков за день отдача падает.
- **Роман**: флирт -> «встречаться» (симпатия 40, любовь 35) -> брак (60/60) -> развод. Один партнёр на игрока.
- **Служба** (MineColonies/Millenaire): нанять жителя при симпатии 25+, жалованье, увольнение; `props.employer`.
- **Просьбы жителей**: «принесите N предметов» за золото и симпатию, срок 12 дней; предметы и золото через игровой инвентарь.
- **Слухи** из хроники двора.
- **Поручения советникам**: маршал (ополчение, копейщики, лучники, наёмники), управляющий (налоги, дань), канцлер (торговый договор или разрыв с соседом). Диалог запускает то же действие карты, что и кнопка в окне, с теми же проверками прав.
Диалоги общего вида генерирует `tools/gen_dialogues.py` (узлы `s_*` и `d_*`), их можно править в JSON руками, условия и эффекты: `npc_ready`, `npc_aff_at_least`, `npc_can_marry`, `npc_interact`, `npc_gift`, `npc_marry`, `npc_hire`, `npc_request_*`, `delegate` и др. (список в `DialogueBridge`).
Состояние сохраняется в `wf_relations.json` мира. Склейка `mc/RelationsMc` не компилировалась.

## Организации (wf-orders)
Гильдии, ордена, братства из датапаков `data/<ns>/wf_orders/*.json` (звания с бонусами, взнос, еженедельные взносы, задания, прошения, соперники). Шесть готовых: торговцев, Орден Щита, воров, кузнецов, учёных, Ночной дозор.
- Вступление за взнос, не больше двух организаций, соперники исключают друг друга, после ухода 20 дней нельзя вернуться; неплательщика исключают.
- Влияние растёт от заданий (принести предметы, внести золото, деяния вроде убийства врагов) и пожертвований; звания повышаются сами.
- Прошения тратят влияние: ссуда из казны или действие карты (налоги, ополчение) через те же проверки прав.
- Казна и сила организаций живут своей жизнью, соперники ежегодно отбирают силу друг у друга. Бонусы званий читает `Orders.perk(игрок, ключ)`.
- Окно: клавиша O или `/wforders`. Представитель в мире: `/wfpeople org <id персонажа> <организация>`, с ним диалог `wf_orders:master`.
- Золото игрока - золотые самородки. Склейка `mc/` не компилировалась.


## wf-progress / wf-origins / общие шины
- wf-progress: уровни, атрибуты, навыки, дерево перков, угрозы по уровню (клавиша P), данные в `wf_progress`.
- wf-origins: 6 рас, 21 класс в 3 ступенях (улучшения по уровню, статам, флагам квестов), 14 профессий с рангами; данные в `wf_origins`. Игровая обвязка (mc) ещё не написана.
- `StatApi` и `ContentApi` в ядре, команда `/wfcontent`.
- Архитектура и разбиение по аддонам: см. ARCHITECTURE.md.

## Виды государств и поселений (всё в JSON)
- wf-realms: `governments.json` (строй, подгонка по расам и местности), `levels.json` (уровни), `doctrines.json` (ветки развития), `laws.json`, `terrains.json`. Свой строй или расу добавляет один JSON в датапаке.
- wf-settlements: `types.json` - стоянка, хутор, деревня, город, столица, крепость, порт, горный посёлок. Поля: условия роста, допустимые здания и лимиты, схема планировки (scatter/ring/grid/linear/walled/terraces), бонусы.

## wf-relations
Отношения вынесены из wf-people в отдельный аддон (нужен wf_people, диалоги подключаются мягко). Окно: клавиша B, команда /wfrel. Расширение контекста диалога идёт через `DialogueBridge.EXTENDERS` в wf-people.

## wf-court
Двор вынесен из wf-people (нужен wf_people). Окно: клавиша V, команда /wfcourt. События: `data/<ns>/wf_events`. Порядок сборки: wf-dialogue, wf-people, wf-court, затем остальные (tools/build-all.sh).

## wf-army
Армии вынесены из wf-war (нужен wf_war). Окно: клавиша L, команда /wfarmy; войны остаются на K. Типы отрядов: `data/<ns>/wf_army/units.json`. Армии ведут время войн через `WarEngine.driver`.

## wf-rts
RTS-панель вынесена из wf-settlements (нужен wf_settle). Клавиша H; сервер по-прежнему шлёт вид `wf_settle:hud`.

## wf-quests
Задания и события мира. Дающие: `villager`, `official[:роль]`, `military`, `ruler`, `org[:id]`/`orgkind:вид`, `board` (доска объявлений). Задания - JSON в `data/wf_quests/wf_quests/*.json`
(шаги kill/fetch/talk/reach/action/level/flag/join_org/wait/choice, параметры, цепочки `requires.quests`, сроки, награды по уровню). Раздел `events` - события государств
с вариантами решения (правитель-игрок выбирает сам, иначе решает ИИ или срабатывает вариант по умолчанию). Игрок с правом `create_quest` (выдаётся грамотой) создаёт задания через общее хранилище ContentApi.
Эффект событий `market` (`[{good, factor, days}]`) двигает рынок wf-trade: чума, голод, урожай и обвал шахт меняют цены. Журнал - клавиша I, команда `/wfquest`; `/wfquest fire <событие> <государство>` для оператора. Мост к диалогам: условия `quest_offers_exist`, `quest_interactable`; эффекты `quest_offers`, `quest_accept`, `quest_interact`.

## wf-forms
Превращения и родовая кровь (независимый аддон). Формы - JSON в `data/wf_forms/wf_forms/*.json`: ступени по прогрессу (`stages`), триггеры (`night`, `full_moon`, `rage`, `hunger`, `water`, `day`, `random`),
источники заражения (`mob` - укус, `event`, `quest`, `item`, `birth`), облик (`shift`), слабости (`sun`, `holy`, `silver`, `water`, `dark`), потребность (кровь/плоть), самообладание (`control`: чем больше, тем чаще удерживаетесь и можно превращаться добровольно),
лечение (`cures`: предмет, золото, флаг задания; `incurable_from` - ступень, после которой пути назад нет), `only_races`/`immune_races`/`exclusive`. Родовая кровь (`level_scale`) растёт с уровнем.
В комплекте 10 форм: вампиризм, оборотничество, драконья кровь, проклятая кровь (случайные превращения), нежить (зомби), благословение, вендиго, дитя прилива, каменное проклятье, звериная кровь.
Окно - клавиша G, команда `/wfform [shift <форма> on|off | feed <форма> | cure <форма> [лечение] | infect|remove <форма>]`. Метки `form:<id>` и `form:<id>:active` работают в `req_flags`/`ban_flags` классов wf-origins.

## wf-trade
Торговля между государствами (независимый аддон). Товары - JSON `data/wf_trade/wf_trade/goods.json` (41 товар): цена `base`, потребление `need` на 100 жителей, `terrain` - во сколько раз местность производит товар,
`races` - спрос по расам, `season` - выпуск по временам года, `item` - предмет игры для личной торговли, `contraband`. Цена рынка зависит от запаса (дефицит до x3, избыток до x0.4);
местность и расы берутся из общей шины DemoApi. Караваны: покупка на рынке отправления, путь в днях (риск нападения, охрана снижает риск и добавляет место), продажа с пошлиной в казну; контрабанду иногда изымают.
Купцы государства (ИИ) возят выгодный товар сами и отдают 5% прибыли казне. Правитель: пошлина 0-30%, эмбарго, купцы вкл/выкл (действия `trade_tariff`, `trade_embargo`, `trade_auto`);
событиям: `trade_shock` (неурожай/расцвет). Игрок: `/wftrade [market <гос>|caravan <куда> <товар> <число> [охрана]|buy|sell]`, окно - клавиша Y. Лавки: `/wftrade shop create "<название>" [категории через запятую]` (игрок, 100 зол., до 3 лавок; оператор: `create_npc` бесплатно) ставит жителя-торговца с именем,
правый клик открывает окно лавки (цены рынка государства + наценка, касса торговца); `shop list|open|remove|margin <id> <%>|collect <id>|buy|sell <id> <товар> <число>`. Наценка до 40%, 5% наценки - сбор в казну.
Караваны в мире: пока игрок в ~110 блоках, караван в пути виден вьючными ламами с возницей и идёт по прямой между столицами государств (по прогрессу пути; сущности служебные, без ИИ, неуязвимые).
Мост к диалогам: условие `trade_market_exists`, эффекты `trade_prices`, `trade_route`, `trade_sell`, `trade_buy` - у жителей пункт «Поговорим о торговле».

- **Дороги.** Видимый караван идёт не по прямой, а по цепочке соседних провинций от столицы к столице (кратчайший путь по графу; если пути нет, прямая). Засада стоит на настоящем отрезке пути.
- **Засады бандитов.** Караван без сильной охраны (меньше 6 человек) при ограблении не исчезает: груз остаётся у разбойников (3-8 человек, зависит от веса). Рядом с игроком они появляются в мире на пути каравана. Разгромите их отрядом (wf-troops) - груз вернётся на рынок отправления, а владелец получит 60% затрат. Через 10 дней добыча пропадает. `/wftrade ambush` - где засады; вкладка «Караваны» показывает их красным.


## Казна и налоги городов
Общая шина `TreasuryApi` (ядро): баланс государства (золото wf_army) и книга «откуда деньги» по источникам; в неё пишут торговые пошлины, налоги городов и события заданий.
В wf-settlements города копят налоги и раз в игровой день отдают долю короны (по умолчанию 25%, серебро -> золото 5:1, оставляя резерв на содержание). Высокая подать портит настроение. Правитель:
`city_crown` (доля 0-60%), `city_tax` (единый налог во всех городах), `city_grant` (грант из казны). Окно «Казна и города» - клавиша U, команда `/wftax`.

## Связка квестов и классов
`wf-origins` теперь имеет склейку (`/wforigin`, `/wforigin list|race|class|learn|drop`, опыт профессий за добычу руды/брёвен, урожай и ковку). Требование класса `quest:<флаг>` (например `quest:trial_of_arms`) выполняется флагами заданий wf-quests.

## Глубина происхождения (wf-origins)
- **Расы:** 8 базовых и 25 подрас (`parent`): подраса наследует бонусы родителя и добавляет свои, для требований остаётся расой-родителем.
- **Классы:** 63, до 4-й ступени. `also_from` - ветви сходятся (класс доступен из нескольких предков), `exclusive` - взаимоисключающие пути, `req_prof` - нужна профессия и звание, `req_flags` - флаги заданий (`quest:<флаг>`). Переобучение `/wforigin retrain` (раз в 30 дней снимает последний класс).
- **Профессии:** 51, основные и специализации (`from`, `min_rank`), `exclusive` - только одна из группы (банкир/скупщик, отравитель/аптекарь, сапёр/знаменосец/муштровщик...), `req_classes` - нужен класс.
- Всё добавляется JSON-файлами в `data/wf_origins/wf_origins/`; генератор встроенных наборов - `tools/gen_origins.py`.
- Окно: клавиша K / `/wforigin` - вкладки «Класс» (дерево по ступеням), «Раса», «Профессии» (с прокруткой), «Итог».

## Демография: расы → государства → поселения
Общая шина `DemoApi` (ядро): доли рас и местностей государства. Источники: объявленное свойство государства `races`/`terrain` («human:60,elf:30»; доля родителя включает подрас) или перепись известных жителей (wf-origins). Потребители: формы власти (wf-realms: `fit`/`why`, `suggest`), виды поселений (wf-settlements: `best`, `fit`), рождение новых NPC (`Origins.assign(..., realm)` берёт расу по составу государства).
Добавлено 9 форм власти (синдикат нор, болотный анклав, сумеречный двор, конклав Покрова, лига гильдий, морское королевство, кочевое ханство, пустынный эмират, совет мудрецов; всего 19) и 9 видов поселений (стойбище, рощевой город, нора, свайная деревня, оазис, монастырь, фактория, теневой рынок, великий чертог; всего 17).
`wf-realms` получил склейку: `/wfrealm [info <id>|gov|unlock|law]`, ежедневное развитие по игровым часам, ИИ для государств без игрока.


## wf-troops

Физическое управление войском и рабочими, как в RTS / Total War / Bannerlord.

- Солдаты - настоящие существа (12 типов из `units.json`: ополченец, пикинёр, лучник, арбалетчик, конница, рыцарь, лекарь и др.), одеваются и вооружаются по данным. Нанять: `/wftroops raise <тип> <число> [государство]` (золотые самородки или казна через TreasuryApi).
- Командный режим - клавиша **R**. Камера отвязывается от игрока и летает над миром, курсор свободен, игра не ходит и не машет предметами.
  - **Камера:** WASD или подвести мышь к краю экрана - сдвиг (Shift быстрее), колесо - высота, средняя кнопка - вращение и наклон, Q/E и стрелки - поворот, **Tab** - вид «Сверху» / «Тактика», Space - к выбранным, Home - к игроку. Также кнопки вверху справа. Камера уходит от игрока не дальше 90 блоков (дальше мир не загружен).
  - **Выбор:** ЛКМ - один, рамка - группа, Shift - добавить/убрать, двойной клик - все того же типа, Ctrl+цифра - запомнить группу, цифра - вызвать (камера летит к ней).
  - **Приказы:** ПКМ по земле - идти, ПКМ по врагу - атаковать, Ctrl+ПКМ - атаковать по пути, Shift+ПКМ - добавить в очередь. Z - стоп, X - держать позицию, C - строй (шеренга, каре, колонна, клин, круг, россыпь), M - поза (агрессивно, оборонительно, не двигаться, не драться), F - собрать выбранных в отряд.
  - **Стройка (B):** меню зданий ближайшего поселения по разделам, цена и склад; выбрали здание - за курсором призрак основания (зелёный - можно, жёлтый - не хватает материалов, красный - место занято); ЛКМ закладывает, Shift - ещё одно. Выбранные рабочие сразу идут строить.
- **Мораль, как в Total War.** У отряда есть мораль: потери, перевес врага и гибель друзей роняют её, сержант (аура 12 блоков) и рыцарь (8) поддерживают и усиливают удар на 15%. Ниже 20% отряд бежит от врага и не слушает приказов, пока не оправится (выше 55% и без врагов рядом). Мораль выбранных видна внизу слева. **Лекарь** лечит до трёх самых раненных рядом (2 здоровья в секунду). Параметры `aura` и `heal` задаются в `units.json`.
- **Осады и крепости.** Оператор ставит крепость: `/wftroops fort create <имя> <радиус> [башен] [государство]` (на месте, где стоит), `fort neutral <имя> <радиус>` - бандитский лагерь (враг всем), `fort garrison <id> <тип> <число>` - гарнизон, `fort list`, `fort remove`. У крепости есть стена с прочностью, башни и гарнизон. Враги в радиусе получают урон от башен (без гарнизона башни слепнут и бьют втрое слабее). Стену бьют осадные расчёты: **таран** (вплотную, 14 в секунду) и **катапульта** (до 30 блоков, 9 в секунду), обычная пехота - слабо (0,4). Защитники чинят стену, пока её не бьют. Когда стена рухнула и защитников не осталось, захватчики держат крепость 20 секунд - и она их. Чужое государство и бандиты враждебны, два частных владельца друг другу не враги. Из армии осадные машины призываются как расчёты таранов.
- **Войны государств.** Солдаты государств, которые воюют (свойство государства `enemies`), сами нападают друг на друга при встрече; это вместе с крепостями, моралью и осадами даёт настоящую войну в мире. Мир между государствами - солдаты друг друга не трогают.
- Выбор части отряда выделяет её в новый отряд, как в Total War. Ближний бой идёт в строю впереди, стрелки позади.
- Рабочие и ремесленники (с wf-settlements): выбрать рабочих, ПКМ по зданию - назначить, Delete - освободить. Стройка и рабочие доступны операторам и владельцу одиночного мира.
- Армии wf-army: `/wftroops muster <id армии> <число>` призывает солдат из абстрактной армии (1 солдат = 10 человек, соответствие типов в `army_map`; осадные машины не призываются), `/wftroops return` возвращает выживших, павшие потеряны.
- Жалованье: солдаты государства стоят денег (поле `upkeep`), раз в игровой день списывается из казны через TreasuryApi; не хватило - четверть солдат дезертирует.
- Типы солдат дополняются файлом `worldforge/wf_troops_units.json` в папке мира.

## Строительство по схемам (Litematica и др.)

Рабочие-строители могут возводить здания по готовым схемам: `.litematic` (Litematica), `.schem` (WorldEdit/Sponge v2–v3) и `.nbt` (ванильные структуры).

1. Положите файлы в `<мир>/worldforge/schematics/` (на сервере - в папку мира сервера) или в `config/worldforge/schematics/`.
2. `/wfsettle schem reload` (или перезапуск) - схемы становятся зданиями `schem_<имя>` в разделе «Схемы» меню стройки (окно поселения и режим командования, клавиша R → B).
3. Выберите рабочих, поставьте призрак здания и подтвердите - строители достроят схему блок за блоком снизу вверх.

Стоимость считается автоматически: камнеподобные блоки → `stone`, остальные → `wood` (1 единица на 8 блоков); работа = блоки / 6; каждая кровать даёт место для жителя.
Рядом можно положить `<имя>.json` с полями здания (`name`, `category`, `cost`, `work`, `housing`, `jobs`, `recipe`…) - они перекроют вычисленные.
Блоки из неустановленных модов пропускаются (в логе предупреждение). Содержимое сундуков и поворот схем пока не поддерживаются.

## wf-genesis: начало игры (создание персонажа)

При первом входе открывается мастер (его же можно вызвать `/wfgenesis`; оператор сбрасывает персонажа `/wfgenesis reset <игрок>`). Шаги:
1. **Раса и подраса** - поправки, особенности и таланты по уровням (из wf-origins).
2. **Внешность** - рост, телосложение, голова, плечи, возраст, шрамы, голос; цвета кожи, волос и глаз с палитрой и тонкой настройкой (тон, насыщенность, яркость); причёска; особенности по расам (уши, рога, клыки, борода, хвост, раскраска, светящиеся глаза...). Рост и ширина реально меняют размер модели и хитбокса; всё видно другим игрокам.
3. **Происхождение** - старт: селянин, горожанин, дворянин столицы, новобранец, торговец, скиталец, отшельник, изгнанник, разбойник или сразу **правитель** деревни, города, столицы (названия и титулы зависят от расы: «Роща», «Горный чертог», «Стойбище»...). Старт даёт вещи, золото, поправки и бонусы или штрафы к очкам.
4. **Поселение** (только для правителя) - название, направление (земледелие, лес, горы, люди), налог, набеги, авторазмещение. После создания поселение основано, открывается панель правителя; своим поселением правитель управляет без прав оператора (в `Colony` есть поле `owner`).
5. **Профессии** - до двух стартовых (звания растут от работы).
6. **Атрибуты** - 28 атрибутов в 7 группах (тело, разум, общение, двор, власть и право, хозяйство и ремесло, дух); 40 очков, дороже после +4, максимум +8.
7. **Класс** (с показом ветвей подклассов) и **навыки** на стартовые очки.
8. **Итог** - сводка характеристик и список замечаний; «Начать игру» применяет всё.

Всё настраивается JSON: `data/<ns>/wf_genesis/*.json` (`config`, `sliders`, `palettes`, `hair_styles`, `features`, `race_look`, `styles`, `tiers`, `focus`, `starts`, `name_pool`); новые атрибуты - в wf_progress (`attributes_ext.json`).
Генератор данных: `tools/gen_genesis.py`.
