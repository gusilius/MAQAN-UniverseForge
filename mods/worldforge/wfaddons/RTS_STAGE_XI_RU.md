# Этап XI — единое управление RTS и НПС

## Управление
- `R` — войти/выйти из командного режима.
- ЛКМ — выбрать юнита; протянуть ЛКМ — рамка; Shift — добавить/убрать; двойной клик — выбрать видимый тип.
- `Ctrl+1..9` — сохранить группу; `1..9` — вызвать; Shift+цифра — добавить к выбору.
- ПКМ по земле — перемещение; Ctrl+ПКМ — атака по пути; Shift+ПКМ — добавить приказ в очередь.
- ПКМ по врагу — прямая атака; гражданские рабочие не получают приказ прямой атаки.
- `Z` — стоп; `X` — удерживать; `C` — следующий строй; `M` — следующая боевая стойка.
- `P` — патруль между текущей позицией отряда и точкой под курсором; Shift+P добавляет приказ в очередь.
- `V` — назначить выбранного персонажа командиром его отряда; Ctrl+V — снять командиров.
- `F` — собрать выбранных солдат в отряд; Delete — освободить выбранных рабочих.
- `B` — меню строительства; Shift при размещении сохраняет выбранный чертёж для следующего размещения.
- `Space` — фокус на выбранных; WASD/края экрана — перемещение камеры; колесо — высота; средняя кнопка — вращение; Tab — вид.

## Единый выбор и инспектор
Командный режим принимает только солдат текущего владельца и физических рабочих поселений, владелец которых совпадает с UUID игрока. Данные владельца и личности рабочего синхронизируются через entity data. У солдата синхронизируются Character ID и боевой опыт.

Инспектор показывает имя, профессию/роль, здоровье, мораль, боевой опыт, Character ID, отряд и состояние текущей работы. Клик по строке фокусирует камеру на выбранной единице.

## Очереди и патруль
- Очередь солдат использует сохранённую очередь приказов отряда.
- Очередь рабочего — до 16 точек маршрута; Shift+ПКМ добавляет точку. По достижении точки физический WFWorker активирует следующую.
- Очередь рабочего сохраняется в Settlement JSON и восстанавливается при загрузке.
- Стоп/удержание очищает очередь рабочего.
- Патруль хранит исходную и конечную точки и чередует их; оба конца и состояние возврата сохраняются в JSON отрядов.

## Проверки и ограничения
Логические тесты покрывают:
- очередь рабочего: добавление, последовательное выполнение, save/load, очистка и лимит;
- патруль: сохранение двух конечных точек и возврат между ними;
- существующие тесты выбора, групп, смешанных приказов, строя, морали, снабжения и командования.

Пока не реализованы: активная панель боевых способностей с cooldown/ресурсной стоимостью; полноценные геройские ветви навыков; единый граф задач «добыть → перенести → доставить → построить»; полноценная multiplayer/runtime-проверка. Эти пункты остаются блокерами принятия Этапа XI.
