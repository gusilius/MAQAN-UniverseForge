# MAQAN Platform

Optional Forge 1.20.1 shell mod. Atlas and WorldForge remain independently installable gameplay mods.

- Open the shell with **P**.
- Workspace switching, retractable explorer/context rails, Dock and a draggable tool window are implemented in the first UI foundation pass.
- Module detection is informational only. It does not claim that the Atlas or WorldForge adapter is connected.
- No orbital, political, settlement or economic values are fabricated.

Next integration stages: shared selection/context contracts, Atlas adapter, WorldForge adapter, persisted window layouts, resize/snap/tab groups, and real module-backed tools.
