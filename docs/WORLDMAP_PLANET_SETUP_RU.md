# Подключение собственной планеты по карте

В базовой поставке MAQAN нет встроенных карт планет, готовых государств или кампаний. Мод не создаёт сценарий: он читает географию пользовательской карты, создаёт измерение и запускает обычную автономную симуляцию.

## 1. Положить карту

Скопируйте свой пакет карты `.worldmap` в:

```text
config/worldforge/maps/<planet-id>.worldmap
```

Поддерживается и распакованная папка с тем же именем:

```text
config/worldforge/maps/<planet-id>/
```

Пакет должен содержать как минимум `meta.json`, `height16.png` и `biomes.png`. Для политической географии также используются файлы провинций/титулов и `world-blueprint.json`, если они присутствуют.

## 2. Имя планеты и её идентификатор

В `meta.json` карты укажите:

```json
{
  "planet_id": "aurelia",
  "display_name": "Аурелия",
  "size_px": [1000, 1000],
  "blocks_per_pixel": 1,
  "sea_level": 63,
  "min_y": -64,
  "max_y": 320,
  "biomes": []
}
```

Остальные обязательные поля `meta.json` и данные изображения должны быть сохранены из вашего пакета. `planet_id` — стабильный технический ID, он должен совпадать с ID карты, используемым генератором. `display_name` — отображаемое имя, его можно менять без изменения ID.

## 3. Подключить измерение

Добавьте в datapack сохранения файл:

```text
<save>/datapacks/<your-pack>/data/worldforge/dimension/aurelia.json
```

Содержимое:

```json
{
  "type": "worldforge:mapworld",
  "generator": {
    "type": "worldforge:image",
    "map": "aurelia"
  }
}
```

Здесь `worldforge:aurelia` — ID измерения, а `aurelia` в поле `map` — ID пакета изображения в `config/worldforge/maps/aurelia.worldmap`. Имена и ID можно выбрать свои; важно, чтобы ссылка `map` совпадала с именем пакета и `planet_id`.

Для нового мира включите datapack при создании сохранения. Измерения Minecraft регистрируются при загрузке datapack; добавление JSON после создания мира не регистрирует новое измерение задним числом.

## 4. Что делает мод после запуска

- Загружает пакет по ID, проверяет его структуру и соответствие `planet_id`.
- Генерирует рельеф и биомы через `MapChunkGenerator`.
- Передаёт географию в общую WorldSim-симуляцию с отдельным ID измерения/карты.
- Создаёт население, поселения и политические образования из географии; затем существующие моды материализуют игровые сущности и канонические записи.
- Сохраняет симуляцию в мире. Повторная загрузка не должна создавать копии уже созданных объектов.

## 5. Важные правила

- Ванильный Overworld остаётся обычным `minecraft:normal`, не superflat.
- Каждое пользовательское измерение должно ссылаться на уникальный `planet_id` и уникальный пакет карты. Не монтируйте один map ID на несколько планет.
- Никакие изображения не входят в мод или datapack-пример: пользователь предоставляет собственный `.worldmap`.
- Кампании, стартовые сценарии, сюжетные задания и обязательные цели не входят в базовую симуляцию. Их можно добавить отдельно как пользовательский datapack/mod, не меняя базовый sandbox.
